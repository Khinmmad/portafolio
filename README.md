# Mi Portafolio Interactivo 🚀

¡Bienvenido! Este es mi portafolio personal, diseñado para ser una experiencia visual impactante y profesional. Aquí puedes encontrar mis proyectos, habilidades y formas de contactarme.

## ✨ Características

- **Diseño Premium**: Interfaz moderna con tema oscuro, efectos de *glassmorphism* y acentos vibrantes.
* **Interactividad**: Efecto de escritura dinámica, cursor con seguimiento de luz y animaciones de revelación al hacer scroll.
- **Optimizado**: Alto rendimiento, carga rápida de imágenes y optimización SEO.
- **Totalmente Responsivo**: Se adapta perfectamente a computadoras, tablets y móviles.

## 🛠️ Tecnologías Usadas

- **HTML5**: Estructura semántica avanzada.
- **CSS3**: Diseño personalizado con variables CSS, animaciones de fotogramas clave y Flexbox/Grid.
- **JavaScript (Vanilla)**: Lógica de interacción y animaciones personalizadas sin dependencias externas.
- **OpenGraph**: Optimización para compartir en redes sociales.

## 🚀 Instalación y Uso

Si quieres probar este proyecto localmente:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/portafolio.git
   ```
2. Abre `index.html` en tu navegador favorito.
